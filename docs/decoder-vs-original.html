This fork's decoder (commit 4f21eb5, Normal mode) against the original JS8Core decoder (commit cba17f3) and the decoder of JS8Call-improved v3.0.3, the current desktop release (published 2026-07-13), run as a test program on the same audio; all on real-style JS8 traffic: 700 messages sent at every speed, never used to choose any decoder setting.   • Stations: 40, from North America, Europe, Asia, Oceania, South America, Africa and the Pacific, including short (W1A), portable (G4DEF/P) and operating-abroad (VE3/G4XYZ) callsigns.
  • Same test at every speed: the same 700 messages in the same order at Normal, Fast, Turbo and Slow, at the same 8 signal levels (-6 to -27 dB in 3 dB steps). Frames per level: Normal 1,913; Fast, Turbo and Slow 1,904 (JS8 packs free text slightly differently at Normal speed).
  • Audio kinds, at every speed: no fading (4 signals per file); fading, ITU model 1 Hz spread / 2 ms delay (4 per file); crowded band (Normal and Slow 60 signals per file, Fast 37, Turbo 19). Each kind plain, + drift (each station's frequency slides up to 0.25 Hz per second), + clock off (each station's clock wrong by up to 1 second) and + drift + clock off: 48 test sets, 718,880 frames, 268,800 messages.
  • Scoring: a frame counts when it is decoded in its file. A message counts as received whole when every one of its frames is decoded. A wrong frame is a decoded frame that was never sent. Callsign hints off in all three decoders. JS8Call-improved v3.0.3 runs through the test program scorecard\desk_ref.cpp (a copy of tools\reference\desktop_wav_reference.cpp with Fast and Turbo added), built against the v3.0.3 release source (tag v3.0.3, commit 4c592bd).
