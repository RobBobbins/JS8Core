Wrong messages: share of decoded messages that are wrong

Every decoder was given the same signals in files. The 95% range is how high or low the true rate could be, given how few wrong messages turned up (exact Poisson range).

DecoderMessages decodedWrongWrong rate1 wrong in every95% rangeAgainst the original
  • "Against the original" is the chance that a gap this big comes from luck alone when both decoders have the same true rate (two-sided test on the split of wrong messages between the two decoders). Under 5% counts as a real difference.
  • All of ours come from the last-try decode, which the original does not have. Each last-try result that reaches the CRC check is a 1 in 4,096 chance of a wrong message.
  • On the noise-only sets (noise4, bnoise, cnoise, enoise; 1,300 files) all three decoders gave 0 wrong messages.
